一、正文与旁注的共享词典

中文或常用名English解释机制详解
智能体Agent根据目标选择行动，并利用环境反馈继续任务的系统。本课程主要讨论由语言模型参与决策的软件智能体。第1章
大语言模型Large Language Model从大量语言材料中学习规律、处理和生成语言的模型。调用工具时，它提出请求，外部程序负责执行。部分模型也能接收图像等输入。第3章
词元Token模型读写文本时使用的单位，可以是词、词的一部分、标点或空白。具体切分由分词器决定。第3章
上下文Context这一次模型调用收到的材料，包括指令、当前请求、历史和工具结果等。保存在别处的资料，需要先取出才能使用。第4章
工具调用Tool Call模型提出一个带工具名称与参数的请求，执行程序检查后调用相应功能，再把结果交回模型。第2章
运行时Runtime本课程中管理一次智能体任务的执行环境：组织模型输入、检查并执行工具、保存进度和控制停止。第1章
系统提示System Prompt应用给模型的高优先级任务规则，说明角色、范围与输出要求。第2章
检索增强生成Retrieval-Augmented Generation先检索与问题有关的材料，再把证据交给模型生成回答。还要核对版本、适用范围和答案是否被证据支持。第9章
幻觉Hallucination模型生成了缺乏事实依据或不符合已有资料的内容，例如编出订单号。第11章
嵌入Embedding把词元、文本等对象映射成可计算向量的方法或表示。向量的编号、维度和相似度含义需要按具体模型解释。第3章
键值缓存Key-Value Cache缓存已经算过的键和值，生成下一个 token 时不用把整段前缀重算一遍。第21章
评估Evaluation用可重复的测试，衡量系统在指定任务上的表现。第11章
上下文窗口Context Window一次调用可使用的序列长度上限，通常以词元计。输入与生成输出是否共用限额，要按模型和服务约定核对。第4章
注意力Attention给不同位置的信息计算权重并汇合的机制。权重分给输入位置；输出词元的概率由后面的输出层给出。第19章
TransformerTransformer现在大语言模型的主流结构，核心是注意力层和前馈网络。第19章
推理Inference使用已有模型处理输入、计算输出的过程。常规推理使用固定的模型参数。第21章
训练Training用数据调整模型参数的过程。预训练、微调、偏好学习都属于训练。第20章
微调Fine-Tuning在已经训练好的模型上继续训练，以适应任务或数据。可以更新全部参数，也可以只更新一部分参数。第20章
监督微调Supervised Fine-Tuning用「请求—答案」成对的数据做监督微调，教模型按格式回答。第20章
低秩适配Low-Rank Adaptation冻结原模型，只训练两个小矩阵的微调方法，省显存。第20章
量化Quantization用更少的位数存权重，比如 16 位压到 4 位，省显存但可能掉精度。第21章
温度Temperature调整采样分布尖锐程度的参数。较低时更集中于高分候选，较高时分布更平缓。第3章
核采样Nucleus Sampling先按概率排序，保留累计概率达到阈值的一组候选，再从中采样。候选数量随分布变化。第3章
上下文工程Context Engineering决定每一轮往上下文里放什么、拿掉什么、按什么顺序放。第5章
预算Budget给一次运行设的轮次、token 或费用上限。到上限就必须停。第4章
停止条件Stop Condition判定一次运行结束的规则，例如给出回复、需要用户输入、达到预算。第12章
动作边界Action Boundary规定 Agent 能做什么、需要谁批准、在什么隔离环境里执行。第13章
沙箱Sandbox限制代码能访问的文件、网络和进程的隔离环境。第13章
审批Approval在任务约定需要确认时，让有权的人核对具体操作及影响。批准范围应与实际执行的对象和内容对应。第13章
幂等Idempotency同一个操作重复执行，所关注的外部效果与执行一次相同。写操作重试的去重保证需要服务端配合。第7章
工作流Workflow按照步骤的依赖、分支或并行关系组织任务的方式。流程中可以包含模型判断，也可以由普通程序完成。第14章
持久状态Persistent State存到磁盘、进程重启后还能恢复的运行状态。第15章
可观测性Observability通过日志、指标和轨迹看出系统内部发生了什么。第16章
轨迹Trace一次运行从头到尾的记录，包含每一步的输入、动作和结果。第16章
基准Benchmark一组公开的测试题和评分规则，用来比较模型或系统。第11章
多次尝试通过率Pass at k让模型生成 k 次，只要有一次通过就算成功；用来衡量有多种解法的问题。第17章
精确率Precision挑出来的里面有多少是对的。第9章
召回率Recall该挑出来的里面，实际挑出了多少。第9章
端到端End-to-End从用户输入一直测到最终结果，覆盖任务的完整过程。第17章
多智能体Multi-Agent多个 Agent 分工协作，各自有上下文和预算。第23章
计算机使用Computer Use让 Agent 看屏幕、点鼠标、敲键盘来操作软件。第23章
模型参数Model Parameters模型通过训练学到的数值，例如矩阵中的权重。参数量表示这些数值的数量。第3章
显存GPU Memory图形处理器上的存储空间，常用于模型权重、中间张量和缓存。实际占用还受上下文长度与并发等因素影响。第21章
浮点运算次数Floating Point Operations完成一次计算所需的浮点运算次数，表示计算量。每秒能完成多少次则是FLOP/s，表示计算速率，两者需要分开记。第22章

预填充Prefill生成开始时处理已有输入、建立相关中间状态的阶段，随后利用其结果预测输出。具体调度取决于服务实现。第21章
解码Decoding在这里指自回归生成阶段：利用已有输入和输出继续预测后续词元，直到满足停止条件。第21章
模型上下文协议Model Context Protocol一个让模型和外部工具按统一格式对接的协议。第6章
工具契约Tool Contract工具的名字、参数、返回值和错误格式的约定，模型和代码都按它对接。第6章
约束解码Constrained Decoding在生成时限制可选 token，让输出直接符合 JSON 等格式。第6章
重排Reranking先粗筛出一批候选，再用更贵的模型逐条打分排序。第9章
技能包Skill Package把某类任务的做法、示例与辅助资源放在一起，按需读取。已读取内容仍会占用本次输入空间。第10章
生成式智能体Generative Agent能生成文本、图像、视频等内容的 Agent，也可以结合工具完成任务。第8章
检查点Checkpoint保存下来的运行状态，供中断后恢复。第15章
重放Replay根据记录重建或继续运行过程。涉及外部写入时，需要先核对既有结果，并使用去重或补偿措施。第15章
对账Reconciliation把日志里的意图和实际结果逐条核对，找出没生效或重复生效的动作。第15章
崩溃窗口Crash Window动作已经生效、但还没记下来的那段时间。崩溃发生在这里，恢复时就说不清做没做。第15章
事务Transaction一组要么全做成、要么全不做的操作，中间失败会回滚。第15章
向量Vector按顺序排列的一组数。在本课程中，它可以表示词或文本的特征，也可以是注意力计算中的中间结果。第9章
控制器Controller运行时中检查预算与停止条件的组件，处理继续、等待和结束。下一阶段交给谁由编排器安排，结果是否合格由验收器判断。第12章
执行框架Harness围绕模型搭建的循环、工具接入和检查代码。本课程用它指具体控制框架，用运行时指管理任务的执行环境。第12章
分发Dispatch校验通过后，按照预先约定的名称映射找到并调用相应工具函数。第2章
前缀缓存Prefix Cache在服务支持且条件满足时，复用相同输入前缀已计算的状态，减少重复处理。第5章
模式定义Schema约定数据里有哪些字段、字段类型和约束的结构说明。格式满足约定后，还要检查任务条件与权限。第6章
分词器Tokenizer把文本切成词元并转换为编号的组件。不同分词器可能给同一句话不同的切分结果。第3章
训练权重Weights模型训练后保存的参数数值。训练程序通过更新这些数值改变模型。第20章
参数量Parameter Count模型中参数数值的数量，常用B表示十亿。第19章
编排器Orchestrator安排任务的先后、分支与交接的组件。它与预算检查、权限判断和结果验收分工合作。第12章
验收器Verifier依据事先约定的完成条件检查结果的组件，例如核对预约记录中的日期与人数。第12章
训练损失Loss训练时衡量预测与目标差距的数值。训练程序据此调整参数。第20章
梯度Gradient描述参数变化会怎样影响损失的量。优化方法利用它选择参数的更新方向与步幅。第20章
logitsLogits模型给各候选词元的原始分数，经 softmax 转换为概率后可用于采样。第19章
softmaxSoftmax把一组分数变成总和为1的非负权重的运算。这里用于注意力权重和候选词元概率。第19章

归一化Normalization按约定方式调整数值尺度的操作，例如 LayerNorm 对每个位置的特征做归一化。第19章
因果掩码Causal Mask在自回归模型中挡住后续位置的注意力连接，使当前位置只能利用允许看到的前文。第19章
