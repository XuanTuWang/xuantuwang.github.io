Transformer 通识：
从 token 到下一个词

“这部电影很好”和“这部电影并不好”，用的词差不多，意思却完全相反。模型要读懂这类差别，不能只给好词加分、坏词减分，还得看清哪个词在修饰哪个词。下面用一个小模型解释 Transformer 怎样完成这段计算，分词方式和数字采用方便手算的教学设定。

正式定义：Transformer 是现在大语言模型（Large Language Model）的主流结构。它把输入变成一串向量（Vector），靠注意力（Attention）让不同位置互相参考，再经前馈网络变换，最后给下一个 词元（Token） 打分。

token 是分词器（Tokenizer）切出的文字单元，向量是一串数字，矩阵乘可以理解为按一张数字表做加权求和。logits 是候选的原始分数，softmax 把这些分数换成总和为 1 的概率。教学图里，小模代表语言模型这一侧：读入上下文（Context）、生成候选；小运代表运行程序（Runtime，下称运行时），负责组织输入、检查并执行工具、保存状态。

运行时里的控制器（Controller）管理预算（Budget）与停止；策略检查、工具执行和验收各有职责。这里的上下文（Context）指这一次请求实际送给模型的输入；窗口是它能装下的容量。

速览

一次前向分五段。分词得到 token，查嵌入（Embedding）表变成向量，注意力让位置之间交换信息，前馈逐位置变换，输出层给下一个 token 打分。矩阵计算都在模型内部完成；小运负责把材料组织好、把工具调用（Tool Call）执行掉。

Q、K、V 都是同一批向量乘不同矩阵得到的，「查询」「键」「值」只是角色名。因果掩码（Causal Mask）挡住未来，多头让模型在几组子空间里分别找关系，归一化（Normalization）与残差让几十层堆得起来。随序列长度平方增长的是注意力分数的个数，随宽度平方增长的是投影与前馈的参数和运算。

先理解它为什么需要看前文

“这部电影很好”和“这部电影并不好”，共享不少词，意思却不同。只把好词加分、坏词减分，会漏掉否定的作用范围和词序。模型需要让一个位置的表示参考其他位置，才能利用这些关系。

向量让词变得可计算，注意力让一个位置的表示参考其他位置。处理“它”时，前面提到的对象就可能提供有用信息。模型通过向量与矩阵运算计算联系，不需要运行时逐条指定它该看哪里。

从三个份额开始理解加权

假设要混合三个位置的信息，给它们的权重分别是 0.6、0.3 和 0.1，对应数值是 10、4 和 0。按份额相乘再相加：0.6×10 加 0.3×4 加 0.1×0，结果为 7.2。这组数字只用于演示加权。

真实注意力把数值换成向量，对每一维进行类似的加权。查询与键用于计算匹配分数，归一化后的权重用于汇合值向量。读公式时，可以分别找出两件事：权重怎样算出来，它们又乘到了哪些信息上。

注意力权重分给输入位置，下一词概率分给词表里的输出候选。两者都经过归一化，回答的问题不同。

看不见未来，怎样完成训练

在因果语言模型里，一个位置只能参考它自己和更早的位置。训练（Training）时虽然可以把整段目标准备好，计算仍要用遮罩阻止偷看后续答案。

位置编码提供顺序线索，残差让原有信息与新计算的更新一起往后传，前馈网络继续变换每个位置的特征。它们共同组成重复堆叠的计算块。日常阅读可以先记住各部件的职责，再按需要核对矩阵形状。

单个注意力权重只反映某个头、某一层的一次分配。完整结果还经过多个头、多层计算和后续变换。

机制

小模和小运的一次预测

输入是「用户问退款进度，订单已处理六天，政策说超过五天」。为了手算，把它按词与标点分成 16 个单元，暂把每个单元当作一个 token。依次是：用户、问、退款、进度、逗号、订单、已、处理、六、天、逗号、政策、说、超过、五、天。真实分词由具体模型的分词器决定。

假设这次计算后，「可以」排在候选前列，接着可能生成「申请升级」。沿着这个候选，来看中间经历了什么。

小运先把订单状态与政策段落组织成这次输入，并保留“只回答、不改订单”的权限限制。分词器将文本转换为编号序列；本例是一行16个编号，形状记作 [1,16]。模型只接收这个序列；订单数据由运行时查询后放进输入。

接下来小模做四步：

  1. 查嵌入表，把每个编号换成 128 维向量。
  2. 用注意力让各位置交换信息，例如让「超过」「五」「天」互相参考，也让「六」「天」「处理」互相参考。
  3. 用前馈逐位置再算一遍。
  4. 取最后一个位置的向量，乘输出矩阵，给词表里 2048 个 token 各打一个分。按上面的设定，「可以」排在前面。

图 19.1 用三个值 10、4、0 演示标量加权：权重 0.6、0.3、0.1，结果 7.2。

小模生成完整回答后，运行时还要核对证据。订单已等六天，政策允许超过五天申请升级，因此「可以申请升级」有依据。验收器（Verifier）检查回答是否符合证据和完成条件，策略层检查拟议动作是否获准。控制器根据这些结果与剩余预算，决定继续还是结束。Transformer 负责生成候选回答。

原始 Transformer 与 decoder-only

2017 年原论文的 Transformer 是编码器（Encoder）加解码器（Decoder）的两段结构。编码器读完整输入。解码器带掩码生成输出，每层有三个子层：带掩码的自注意力、读取编码器输出的交叉注意力、前馈。

今天常见的大语言模型多为 decoder-only。它去掉整个编码器，也去掉解码器里的交叉注意力，只剩带因果掩码的自注意力和前馈，一层层堆叠，每个位置只看自己和左边。对照图 19.2 时，左支整体去掉，右支里的交叉注意力子层也去掉。

原图还有几处与现在常见做法不同：位置用正余弦绝对位置编码，归一化放在残差相加之后（post-norm），前馈用 ReLU。后文讲的 RoPE、pre-norm、RMSNorm、SwiGLU 是后来常见的替换，图里没有。

读图时从底部往上看，Embedding 先把 token 变成向量。Attention 汇集相关位置的信息，Feed Forward 再逐位置处理。顶部的 Linear 与 Softmax 得到候选分数和概率。左右之间的连线指向交叉注意力，这是区分原图与 decoder-only 的一个线索。

嵌入：查表得到向量

分词器把文本切成 token，每个 token 有一个整数编号，编号本身不带含义。嵌入表是一张 [V,d] 的矩阵，按编号取一行，这一行的数值是训练出来的。查表主要是访存，通常不计入浮点运算；实现若做类型转换或量化（Quantization）反量化，仍可能有额外计算。教学配置 V=2048、d=128，这张表有 262,144 个参数。

E∈RV×d,X=E[ids]∈RB×T×dE \in \mathbb{R}^{V \times d}, \qquad X = E[\text{ids}] \in \mathbb{R}^{B \times T \times d}E∈RV×d,X=E[ids]∈RB×T×d

V 是词表大小，d 是向量宽度，B 是批大小，T 是序列长度，ids 是形状 [B,T] 的编号。B=1、T=16、d=128 时，X 的形状是 [1,16,128]。

位置：怎样让词序进入打分

注意力只比较向量，本身不知道谁在前谁在后，所以要把位置信息送进去。词序会改变语义：「狗咬人」与「人咬狗」用词相同，意思相反。重复的词也要靠位置区分，两个「是」共享同一个词嵌入。

早期做法是把正余弦或可学习的绝对位置向量 p 加到嵌入 x 上。因为后面的 Q、K、V 都由相加后的向量算出，位置会同时进入 Q 和 K，所以它能直接影响注意力打分，也能参与编码词序。它的局限是：每个位置只有一个固定编号，训练时没见过的长度没有可靠表示；两个词之间的相对距离，要模型自己从两个绝对位置里学。

现在常见的旋转位置编码（Rotary Position Embedding，RoPE）换了一条路。可以把它想成一根指针：位置每往后一格，指针就多转一个固定角度；两个位置的夹角只由格差决定。RoPE 在注意力里按位置旋转 Q 和 K，V 保持原样，嵌入不加位置向量。两个位置的 Q、K 点积因此带上相对位移，相对位置直接进入打分。

但点积大小还取决于向量内容，距离与分数不构成单调关系：相邻位置可能分数更低，远距离也可能更高。外推到远超训练长度时，仍要调整旋转频率并实测。

可选阅读：旋转之后点积为什么只含相对位移。

q~m=Rmqm,k~n=Rnkn,q~m⊤k~n=qm⊤Rm⊤Rnkn=qm⊤Rn−mkn.\begin{aligned} \tilde{q}_m &= R_m q_m, \qquad \tilde{k}_n = R_n k_n,\\ \tilde{q}_m^\top \tilde{k}_n &= q_m^\top R_m^\top R_n k_n = q_m^\top R_{n-m} k_n . \end{aligned}q~​m​q~​m⊤​k~n​​=Rm​qm​,k~n​=Rn​kn​,=qm⊤​Rm⊤​Rn​kn​=qm⊤​Rn−m​kn​.​

m 与 n 是两个位置，R 是位置对应的旋转矩阵（R 的转置乘 R 等于相对位移的旋转），q 与 k 是原始查询和键向量。

注意力：Q、K、V 只是向量

每个位置的向量 X 乘三个矩阵，得到这个位置的 Q、K、V 三个向量；把 16 个位置拼起来，就是三个 [16,d] 的矩阵。每个位置的 Q 去和各位置的 K 匹配，K 是每个位置摆出来的匹配线索，V 是匹配上之后被取走的内容。这套比喻只帮忙记角色；实际计算是矩阵乘、点积、softmax 与加权求和。

Q=XWQ,K=XWK,V=XWVQ=XW_Q, \qquad K=XW_K, \qquad V=XW_VQ=XWQ​,K=XWK​,V=XWV​
S=QK⊤dk+M,A=softmax⁡(S),H=AV.\begin{aligned} S &= \frac{QK^\top}{\sqrt{d_k}} + M,\\ A &= \operatorname{softmax}(S),\\ H &= AV. \end{aligned}SAH​=dk​​QK⊤​+M,=softmax(S),=AV.​

X 的形状是 [T,d]，W_Q 与 W_K 是 [d,d_k]，W_V 是 [d,d_v]。Q、K 是 [T,d_k]，V 是 [T,d_v]，S 与 A 是 [T,T]，M 是因果掩码，softmax 按行做，H 是 [T,d_v]。

因果掩码把未来位置的分数设为负无穷，softmax 之后这些位置的权重为 0。训练时每个位置只能看自己和左边，不能从后文抄答案；推理时只需保留过去位置的 K、V，也就是键值缓存（Key-Value Cache）。

除以 √d_k 是为了让分数的大小不随头维变大。不缩放时，分数大了，softmax 容易被一个位置主导。缩放不改变谁最大，只改变分布的平陡。

可选阅读：若 q、k 的各维独立、均值 0、方差 1，则点积的方差约等于 d_k，所以除以 √d_k 把方差拉回 1。

Var⁡(∑i=1dkqiki)≈dk\operatorname{Var}\left(\sum_{i=1}^{d_k} q_i k_i\right) \approx d_kVar(i=1∑dk​​qi​ki​)≈dk​

多头把 d 切成 h 份，每份 d_k=d/h，各自算一遍注意力，再拼回来乘 W_O。

不同头可以学到不同的关系模式，但不能保证每个头都有一个人能命名的分工。教学配置 h=4、d=128，每头 32 维；Q、K、V 的形状是 [1,4,16,32]，分数矩阵是 [1,4,16,16]，拼回 [1,16,128]。

softmax 的数字可以手算。设头维为 4（这是单独的小算例，与教学配置的 32 无关），三个原始分数是 4、1、0。不缩放时，指数是 54.60、2.72、1.00，总和 58.32，概率约为 93.6%、4.7%、1.7%。除以 √4=2 之后，分数变成 2、0.5、0。指数是 7.39、1.65、1.00，总和 10.04，概率约为 73.6%、16.4%、10.0%。

前馈与预测：逐位置变换，再给词表打分

注意力负责跨位置混合，前馈网络（Feed-Forward Network，FFN）负责在每个位置上单独做非线性变换。它先升维再降维。原始 Transformer 用两层线性加 ReLU（一种把负数截成 0 的激活函数），扩张比 4；现在常见门控版本 SwiGLU，用三个矩阵，扩张比 8/3 左右。

FFN⁡(x)=W2 ϕ(W1x+b1)+b2\operatorname{FFN}(x) = W_2\,\phi(W_1x+b_1)+b_2FFN(x)=W2​ϕ(W1​x+b1​)+b2​
SwiGLU⁡(x)=W2(SiLU⁡(W1x)⊙W3x)\operatorname{SwiGLU}(x)=W_2\big(\operatorname{SiLU}(W_1x)\odot W_3x\big)SwiGLU(x)=W2​(SiLU(W1​x)⊙W3​x)

x 是单个位置的向量，W_1 与 W_3 把 d 维升到 d_ff，W_2 降回 d 维，⊙ 是逐元素乘，SiLU(z)=z·σ(z)。三个矩阵的参数量（Parameter Count）约为 3·d·d_ff；取 d_ff≈(8/3)d，就是 8d²。教学配置省略偏置。

教学配置 d=128、d_ff=344，三个矩阵合计 3×128×344=132,096 个参数；注意力四个投影合计 4×128²=65,536。单看一层内部，前馈参数约是注意力的两倍。

最后一层取最后一个位置的向量 h_T，做归一化，乘输出矩阵 W_out，得到 V 个 logits。softmax 变成概率，再按温度（Temperature）与采样策略挑一个 token。权重绑定（weight tying）时 W_out 与嵌入表共享，参数量不再另算；不绑定时要多一张 V×d 的表。

h_T 是最后一个位置的向量，W_out 是 [V,d]，z 是 [V] 的原始分数，τ 是温度，p 是词表上的概率。这一步矩阵计算由模型完成。小运负责把工具结果放进上下文、保存状态；控制器按预算和停止条件（Stop Condition）判断继续、回复还是停下。策略检查负责核对证据，验收由评估（Evaluation）程序完成。

归一化与残差：让深堆叠能训练

归一化把每个位置的激活拉回稳定范围。层归一化（Layer Normalization，LayerNorm）减均值、除标准差，再乘缩放加偏移；均方根归一化（Root Mean Square Normalization，RMSNorm）只除均方根，少一个偏移参数。一个块里通常有两处归一化，输出前还有一处最终归一化。

LN⁡(x)=γ⊙x−μσ2+ϵ+β\operatorname{LN}(x)=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\betaLN(x)=γ⊙σ2+ϵ​x−μ​+β
RMSNorm⁡(x)=γ⊙x1d∑i=1dxi2+ϵ\operatorname{RMSNorm}(x)=\gamma\odot\frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^{d}x_i^2+\epsilon}}RMSNorm(x)=γ⊙d1​∑i=1d​xi2​+ϵ​x​

x 是单个位置的向量，μ 是均值，σ² 是方差，γ 与 β 是学到的缩放和偏移，ε 是防止除零的小常数。举例：x=[1,2,3,4]，均值 2.5，标准差 √1.25≈1.118。LayerNorm 输出约为 [-1.34,-0.45,0.45,1.34]。均方根是 √7.5≈2.74，RMSNorm 输出约为 [0.37,0.73,1.10,1.46]，均值不为 0。

残差把分支输出加回原向量。pre-norm 先归一化再进注意力或前馈，结果加回；post-norm 先加残差再归一化。pre-norm 的主路没有归一化，梯度（Gradient）能沿残差直通，深堆叠通常更好优化。

x′=x+Attn⁡(Norm⁡(x)),x′′=x′+FFN⁡(Norm⁡(x′)).\begin{aligned} x' &= x + \operatorname{Attn}(\operatorname{Norm}(x)),\\ x'' &= x' + \operatorname{FFN}(\operatorname{Norm}(x')). \end{aligned}x′x′′​=x+Attn(Norm(x)),=x′+FFN(Norm(x′)).​

x 是残差流，形状始终是 [B,T,d]。Attn 与 FFN 是两条分支，Norm 是归一化。两条分支都只往残差流上加东西，不替换它。归一化与残差主要解决优化稳定性；词序和事实仍要靠位置编码、注意力与训练数据学。

这张表只算一次前向的乘法，不含 softmax、归一化、激活函数与访存。它说明三件事：

  • 参数上，这个 1 层小配置里嵌入表最大（262,144，占 57.0%）。前馈其次（132,096，占 28.7%），注意力 65,536（占 14.2%）。每多一层，约增加 19.8 万个参数，不到两层，层内参数就超过嵌入表。
  • 运算上，短序列时前馈约占六成，注意力的四个投影约占三成。
  • 序列变长，分数矩阵的 4BT²d 会反超投影；临界点在 T>2d，教学配置 d=128 时是 T>256。

说「参数大头」时，必须先说明比较的是层内还是整个模型。

成本与限制

注意力的平方项是训练侧的主要约束。序列长度翻倍，分数矩阵的元素涨四倍。4096 长度的单层单头分数矩阵有 1677 万个元素，按 2 字节存就是 32 MiB。层数与头数再乘上去，朴素实现的峰值显存（GPU Memory）会很快见底。

FlashAttention（Dao 等，2022）要分清两件事。第一，它没有消除 T² 的运算量：算分数和加权求和的乘加次数基本不变，反向传播还会重算一部分，运算量略增。

第二，它省的是搬运和占用：GPU 显存（HBM）与片上缓存之间来回读写的数据变少。完整的 T×T 分数矩阵不必整块放在显存里（分块计算，用在线 softmax 合并）。长序列的注意力常常卡在搬运而不是乘法上，所以搬运少了就更快、更省显存。它是精确注意力，数学结果与标准做法相同。

推理侧的账不同。每生成一个 token，都要读历史的键和值，这份键值缓存随层数、长度、并发数与键值头数线性增长，不按 T² 增长。长上下文、高并发时，它常与权重同量级，甚至更大。第 21 章的 7B 例子是 4096 上下文、8 并发要 16 GiB，权重约 14 GB（十进制）。训练侧和推理侧的账混在一起，会高估或低估显存。

参数怎么分配，取决于比较的对象。扩张比换参数，参数换显存。宽度翻倍，投影与前馈的参数都涨四倍。宽度从 128 涨到 4096（32 倍），以 Q 投影为例，参数和运算涨约 1,024 倍。T=16 时，这个投影从约 0.524 MFLOPs 涨到约 5.4 亿次。

位置编码有长度外推的代价。RoPE 在远超训练长度的序列上需要调整频率；直接沿用短序列的旋转频率，效果会下降（推断）。

真实模型的宽度与层数比教学配置大几个数量级。手算得到的量级适合判断可行性；形状规则不变，绝对数字要按实际配置重算。
