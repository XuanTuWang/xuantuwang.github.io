附录 B · 公式与数值速查

这一页把散在各章的公式收拢，方便估算时直接翻。每条给出适用条件，能写成公式的写公式，并附一个算例，自己代别的数进去即可。

B.1 上下文预算

适用：为一次推理分配窗口。

I+H+U+T+E+M+Y≤WI+H+U+T+E+M+Y\le WI+H+U+T+E+M+Y≤W
符号含义
I指令与示例
H对话历史
U当前请求
T工具定义
E证据
M记忆与技能
Y生成预留
W窗口上限

算例：W 取 8192，Y 取 1024，输入预算最多 7168 tokens。

B.2 键值缓存显存

适用：估算长上下文服务的显存上限。键值（Key-Value，KV）缓存随序列长度线性增长。

MKV=2LBTHKVdsM_{\mathrm{KV}}=2LBTH_{\mathrm{KV}}dsMKV​=2LBTHKV​ds
符号含义
L层数
B并发批大小
T序列长度
H_KV键值头数
d头宽
s每个元素的字节数
2键与值各一份

算例一：L 取 32、H 取 32、d 取 128、BF16，每个 token 每请求约 512 KiB。

算例二：假设 80 层、批大小 1、长度 4096、头宽 128，每元素 2 字节。键值头数分别取 64、8、1 时，缓存为 10 GiB、1.25 GiB、160 MiB；对应三种注意力设计。

算例三：沿用算例一的层数、头数与精度，长度 8192 时单请求约 4 GiB；8 并发约 32 GiB。

B.3 矩阵乘与注意力浮点运算

适用：估算一次前向的计算量。浮点运算次数（Floating Point Operations，FLOPs）用来估算计算量。

Fmatmul≈2mkn,FQKV≈6BTd2.\begin{aligned} F_{\mathrm{matmul}}&\approx 2mkn,\\ F_{\mathrm{QKV}}&\approx 6BTd^2. \end{aligned}Fmatmul​FQKV​​≈2mkn,≈6BTd2.​

算例：B 取 1、T 取 16、d 取 128，三个投影合计约 1.573 MFLOPs。玩具模型整层约 7.0 MFLOPs。

B.4 权重存储

适用：判断一份权重放不放得下。

Mweights=PsM_{\mathrm{weights}}=PsMweights​=Ps

P 是参数量，s 是每个参数的字节数。算例：460,160 个参数，FP16 存约 0.92 MB，FP32 存约 1.84 MB。实际服务还需计算缓存和工作缓冲。

B.5 训练与微调开销

适用：粗算训练预算，或判断该用全参还是低秩。

混合精度、Adam 优化器的一个常见估算如下，P 是参数量，单位为字节。它只计模型状态，实际还需预留激活与运行时缓冲。

Mstate≈P(2+2+4+8)=16PM_{\mathrm{state}}\approx P(2+2+4+8)=16PMstate​≈P(2+2+4+8)=16P

四项分别是权重、梯度、FP32 主权重与 Adam 状态。具体训练实现可能采用不同精度或分片方式。

算例一：低秩适配只训练两个小矩阵。宽度 4096、秩取 8 时，可训练参数约 6.6 万，占原权重 0.39%。

算例二：混合精度训练每个参数约 16 字节，这部分常被忽略。

B.6 接口成本换算

适用：把 token 用量换成钱。

C=Ninpin+Noutpout106C=\frac{N_{\mathrm{in}}p_{\mathrm{in}}+N_{\mathrm{out}}p_{\mathrm{out}}}{10^6}C=106Nin​pin​+Nout​pout​​

N 是 token 数，p 是每百万 token 的单价，C 与单价使用同一货币单位。

算例一：输入 2 美元每百万 token、输出 10 美元每百万 token，一次 2000 输入加 500 输出的响应约 0.009 美元。

算例二：一次 8 次调用的 Agent 用 3 万输入加 4 千输出，约 0.10 美元，是单次响应的 11 倍。一万次任务约 1000 美元。

B.7 前缀缓存收益

适用：多轮或多次请求共享同一段长前缀。

C=(Nmiss+rNhit)p106C=\frac{(N_{\mathrm{miss}}+rN_{\mathrm{hit}})p}{10^6}C=106(Nmiss​+rNhit​)p​

p 是每百万 token 的单价；r 是命中部分相对原价的计费比例。这里假设 r=0.1，即命中部分按原价的一成收费。

算例：五个请求各一万输入，公共前缀八千 tokens，首个请求冷启动。不缓存时未命中 tokens 五万，成本 0.1000 美元。启用复用后未命中一万八、命中三万二，成本 0.0424 美元。

换算：token 加权命中率约 64%，成本降约 58%。

B.8 串行改并行的收益

适用：多个互不依赖的工具调用。

tserial=∑iti,tparallel=tdependent+max⁡jtj.\begin{aligned} t_{\mathrm{serial}}&=\sum_i t_i,\\ t_{\mathrm{parallel}}&=t_{\mathrm{dependent}}+\max_j t_j. \end{aligned}tserial​tparallel​​=i∑​ti​,=tdependent​+jmax​tj​.​

第一行相加所有步骤；第二行把必须顺序执行的部分，与并行分支中最慢的一个相加。这里忽略调度与通信的额外耗时。

算例：串行 6.4 秒；改成两次模型调用加三个并行读取后约 2.8 秒。前提是三次读取互不依赖。

B.9 换算提醒

  • token 与汉字没有固定换算比例，预算以实际分词器的计数为准。
  • 显存与带宽单位统一到字节或字节每秒再比较，别把 GiB 与 GB 混着除。
  • 示例单价用于教学，估算实际费用时要代入所用服务的现行价格。
